# e-plantShopping

Paradise Nursery es una aplicación de comercio electrónico desarrollada con React y Redux Toolkit para una tienda de plantas de interior.

La aplicación permite explorar plantas organizadas por categorías, agregar productos al carrito, modificar cantidades, eliminar artículos y calcular dinámicamente el costo total de la compra.

## Funcionalidades

- Página de inicio de Paradise Nursery.
- Catálogo de plantas organizado por categorías.
- Información de cada planta: imagen, nombre, descripción y precio.
- Carrito de compras administrado con Redux.
- Contador dinámico de productos.
- Incremento y disminución de cantidades.
- Eliminación de productos del carrito.
- Cálculo del costo total.
- Navegación entre Inicio, Plantas y Carrito.
